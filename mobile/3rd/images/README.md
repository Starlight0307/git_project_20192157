# 이미지 폴더

이 폴더에 포트폴리오 사이트에서 사용할 이미지들을 추가하세요.

## 필요한 이미지 목록

### 1. 프로필 이미지
- **파일명**: `profile.jpg`
- **권장 크기**: 500x500px (정사각형)
- **용도**: Hero 섹션의 프로필 사진

### 2. About 이미지
- **파일명**: `about.jpg`
- **권장 크기**: 800x600px (4:3 비율)
- **용도**: About 섹션의 보조 이미지

### 3. 프로젝트 이미지
- **파일명**: `project1.jpg`, `project2.jpg`, `project3.jpg`, `project4.jpg`
- **권장 크기**: 800x500px (16:10 비율)
- **용도**: Projects 섹션의 각 프로젝트 썸네일

## 이미지 최적화 팁

1. **파일 크기**: 각 이미지는 500KB 이하로 최적화
2. **포맷**: JPEG (사진), PNG (그래픽/로고), WebP (최신 브라우저 지원)
3. **해상도**: 웹용으로 72-96 DPI 권장

## 온라인 무료 이미지 사이트

- Unsplash: https://unsplash.com
- Pexels: https://pexels.com
- Pixabay: https://pixabay.com

## 이미지 최적화 도구

- TinyPNG: https://tinypng.com
