PROJECT TELEMETRY

한국 F1 팬들을 위한 가장 빠르고 정확한 데이터 허브

0.001초의 차이를 읽다

PROJECT_TELEMETRY는 모터스포츠의 정점인 Formula 1의 방대한 데이터를 누구나 한눈에 쉽게 이해할 수 있도록 시각화하여 제공하는 웹 플랫폼입니다.
언어의 장벽 없이, 파편화된 정보를 찾아다닐 필요 없이, 오직 레이스의 본질과 데이터에 집중할 수 있는 최고의 환경을 대한민국 F1 팬들에게 선사합니다.

실시간 데이터

그랑프리 일정, 실시간 경기 결과, 그리고 세션별 기록을 한글로 가장 빠르게 업데이트합니다.

순위 & 통계 분석

드라이버와 컨스트럭터의 치열한 챔피언십 경쟁 상황과 역대 F1의 역사적인 통계를 시각화합니다.

서킷 가이드

전 세계 24개 서킷의 레이아웃, DRS 존, 타이어 컴파운드 등 시청에 필요한 필수 정보를 제공합니다.

공식 굿즈 연동

글로벌 스토어와 연동하여 응원하는 팀의 최신 머천다이즈를 실시간 환율 기반의 원화로 쉽게 확인합니다.

DATA SOURCES

본 사이트는 안정적이고 정확한 역대 / 실시간 F1 데이터를 제공하기 위해 Jolpica F1 API (Ergast Developer API)를 코어 엔진으로 구동하고 있습니다.
또한, 굿즈 샵의 실시간 환율 계산을 위해 Open Exchange Rates API를 활용하며, 사이트 내 모든 이미지와 로고는 각 구단의 공식 미디어 소스 및 위키 오픈 데이터를 참조합니다.
